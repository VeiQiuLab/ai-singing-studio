# AI Singing Studio

独立的 Windows 11 本地唱歌工作台。可分离人声和伴奏、用已登记的 RVC 角色做片段试唱或整首翻唱，也可以在同一位置切换音轨、调整混音并导出 WAV 或 MP3。

1. 在 Windows x64 安装 Python 3.11（带 Tk）、FFmpeg、Git 和 uv。双击 `启动.cmd`，用「设备测试音」确认工作台能打开和导出。
2. 在项目目录运行 `python -B setup_engines.py --with-rmvpe`，恢复分轨和换声所需的固定版本。已有引擎目录时，可用 `--runtime` 和 `--register-existing` 重新登记。
3. 导入有授权的 RVC 角色模型和自己的音频，先试唱一小段，再按需要翻唱整首。

[启动、引擎准备与回滚](启动与回滚.md) · [音色与训练](音色与训练.md) · [试唱与整首验收](试唱与整首验收.md) · [备份恢复验收](备份恢复验收.md)

这个备份保存应用源码、依赖版本、测试和说明。安装时从原发布方恢复引擎和通用模型。清理旧工作区前，把自己的角色 `.pth`／`.index`、授权记录 `studio-data/voices`、要保留的 `studio-data/jobs` 和成品 WAV／MP3 复制到独立位置。角色登记引用文件路径，换目录后可以重新登记。

想释放空间时，可以在确认新副本正常后清理可重建的引擎环境、下载缓存和测试中间产物。若当前仍在使用原工作台，先在新位置完成一次试唱再清理原目录。
